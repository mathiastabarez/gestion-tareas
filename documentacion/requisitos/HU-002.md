# HU-002 - Crear una tarea

Estado: Pendiente
Fecha:

## Historia

Como usuario,
quiero crear una tarea,
para registrar un trabajo que necesito realizar.

## Criterios de aceptación

- [ ] La Web muestra un formulario con título, descripción y fecha de vencimiento.
- [ ] El título es obligatorio, se guarda sin espacios exteriores y admite hasta 150 caracteres.
- [ ] La descripción es opcional, admite hasta 1000 caracteres y se guarda como `NULL` cuando está vacía.
- [ ] La fecha de vencimiento es opcional y puede ser anterior a la fecha actual.
- [ ] Una tarea nueva se guarda con estado `Pendiente` y fecha de creación en UTC.
- [ ] Los datos inválidos no se guardan y la Web muestra los errores correspondientes.
- [ ] La API devuelve `201 Created` con la ubicación del nuevo recurso.
- [ ] Después de crear la tarea, la Web vuelve a la lista y la tarea aparece en los resultados.

## Tareas

- [ ] Implementar en `Tarea` la creación, validación y normalización de datos.
- [ ] Crear `CrearTareaInput` y agregar el caso de uso de creación a `ITareaService` y `TareaService`.
- [ ] Agregar a `ITareaRepository` la creación con devolución del identificador generado.
- [ ] Implementar el `INSERT` parametrizado con `OUTPUT INSERTED.Id` en `SqlTareaRepository`.
- [ ] Crear `CrearTareaRequest` y su mapeo a `CrearTareaInput`.
- [ ] Implementar `POST /api/tareas` mediante `CreatedAtAction`.
- [ ] Crear en la Web el modelo, mapeador, formulario y acción para crear tareas.
- [ ] Agregar al cliente HTTP la operación de creación.
- [ ] Agregar pruebas unitarias para estado inicial, fecha de creación, normalización, validaciones, servicio y mapeadores.
- [ ] Comprobar manualmente la creación desde la Web hasta SQL Server.
