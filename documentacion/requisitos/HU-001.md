# HU-001 - Consultar las tareas

Estado: En Curso
Fecha:

## Historia

Como usuario,
quiero consultar mis tareas,
para conocer el trabajo registrado y su estado.

## Criterios de aceptación

- [ ] La Web muestra una lista paginada de tareas.
- [ ] La lista se ordena por fecha de creación descendente y luego por identificador descendente.
- [ ] La página inicial es `1`, el tamaño predeterminado es `10` y el máximo permitido es `50`.
- [ ] Se puede buscar por título o descripción.
- [ ] Se puede filtrar por estado.
- [ ] La búsqueda y el filtro pueden utilizarse juntos y se conservan al cambiar de página.
- [ ] Una página posterior a la última muestra una lista vacía sin producir un error.
- [ ] Cuando no existen resultados, la Web muestra un mensaje comprensible.
- [ ] Se puede ver el detalle completo de una tarea.
- [ ] Consultar un identificador inexistente produce una respuesta `404` y un mensaje comprensible.

## Tareas

- [ ] Crear `Tarea` y `EstadoTarea` en `Domain` con lo necesario para representar datos existentes.
- [ ] Crear los modelos de búsqueda y resultado paginado en `Application`.
- [ ] Definir en `ITareaRepository` las operaciones de búsqueda y consulta por identificador.
- [ ] Implementar las consultas parametrizadas en `SqlTareaRepository` con filtros, `COUNT`, orden estable, `OFFSET` y `FETCH`.
- [ ] Implementar en `TareaService` la consulta paginada, la normalización del texto y la consulta por identificador.
- [ ] Crear `TareaNoEncontradaException` y convertirla en `404 ProblemDetails`.
- [ ] Registrar `TareaService` y `SqlTareaRepository` en las extensiones de dependencias.
- [ ] Crear los DTOs, mapeadores y endpoints `GET /api/tareas` y `GET /api/tareas/{id}`.
- [ ] Crear en la Web el cliente HTTP, modelos, mapeadores, controlador y vistas de lista y detalle.
- [ ] Implementar los controles de búsqueda, estado y paginación.
- [ ] Agregar pruebas unitarias para filtros, valores de paginación, resultados vacíos, tarea inexistente y mapeadores.
- [ ] Comprobar manualmente la consulta desde la Web hasta SQL Server utilizando datos temporales y eliminarlos al finalizar.

## Notas

Depende de `TEC-001`, `TEC-002` y `TEC-003`.

No incluye la creación, edición ni eliminación de tareas.
