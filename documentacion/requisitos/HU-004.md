# HU-004 - Eliminar una tarea con confirmación

Estado: Pendiente
Fecha:

## Historia

Como usuario,
quiero eliminar una tarea con confirmación,
para quitar registros que ya no necesito sin hacerlo accidentalmente.

## Criterios de aceptación

- [ ] La Web muestra los datos de la tarea antes de eliminarla.
- [ ] La eliminación requiere una confirmación explícita.
- [ ] Cancelar la confirmación conserva la tarea sin cambios.
- [ ] Confirmar elimina permanentemente la tarea.
- [ ] Eliminar una tarea inexistente produce una respuesta `404` y un mensaje comprensible.
- [ ] Después de eliminar, la Web vuelve a la lista y la tarea deja de aparecer.

## Tareas

- [ ] Agregar el caso de uso de eliminación a `ITareaService` y `TareaService`.
- [ ] Agregar a `ITareaRepository` la operación de eliminación.
- [ ] Implementar el `DELETE` parametrizado en `SqlTareaRepository`.
- [ ] Implementar `DELETE /api/tareas/{id}`.
- [ ] Crear en la Web la vista de confirmación y las acciones de eliminación y cancelación.
- [ ] Agregar al cliente HTTP la operación de eliminación.
- [ ] Agregar pruebas unitarias para eliminación correcta y tarea inexistente.
- [ ] Comprobar manualmente la confirmación, cancelación y eliminación desde la Web hasta SQL Server.

## Notas

Depende de `HU-001` y `HU-002`.

La eliminación es física. No se implementará recuperación ni eliminación lógica.
