# TEC-001 - Crear la solución y la estructura de proyectos

Estado: Completado

Fecha:05/10/2026

## Objetivo

Crear en la raíz del repositorio una solución compilable con todos sus proyectos, dependencias y configuración estructural, sin implementar funcionalidades.

## Tareas

- [x] Crear la solución `GestionTareas.sln` en la raíz del repositorio.
- [x] Crear `GestionTareas.Web` como proyecto ASP.NET Core MVC.
- [x] Crear `GestionTareas.Api` como proyecto ASP.NET Core Web API.
- [x] Crear `GestionTareas.Application` como biblioteca de clases.
- [x] Crear `GestionTareas.Domain` como biblioteca de clases.
- [x] Crear `GestionTareas.Infrastructure` como biblioteca de clases.
- [x] Crear `GestionTareas.Database` como SQL Server Database Project.
- [x] Crear `GestionTareas.Tests` como proyecto de pruebas unitarias.
- [x] Configurar los proyectos .NET con destino `net10.0`.
- [x] Comprobar que `Nullable` e `ImplicitUsings` estén habilitados.
- [x] Agregar todos los proyectos a la solución.
- [x] Eliminar controladores, modelos, páginas y pruebas de ejemplo generados por las plantillas.
- [x] Agregar la referencia de `Application` a `Domain`.
- [x] Agregar las referencias de `Infrastructure` a `Application` y `Domain`.
- [x] Agregar las referencias de `Api` a `Application`, `Infrastructure` y `Domain`.
- [x] Agregar las referencias de `Tests` a `Api`, `Application` y `Domain`.

## Notas

`Web` consumirá la API mediante HTTP y no debe referenciarla como proyecto.

`Api` referencia directamente a `Domain` porque sus mapeadores utilizan `Tarea` y `EstadoTarea`.

No se configurarán todavía cadenas de conexión, `HttpClient`, OpenAPI, serialización JSON, inyección de servicios ni manejo de errores. Esos elementos pertenecen a `TEC-003`.

No se deben agregar credenciales, cadenas de conexión reales ni archivos generados por el entorno.
