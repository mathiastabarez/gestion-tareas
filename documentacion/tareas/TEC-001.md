# TEC-001 - Crear la solución y la estructura de proyectos

Estado: Pendiente

Fecha:

## Objetivo

Crear en la raíz del repositorio una solución compilable con todos sus proyectos, dependencias y configuración estructural, sin implementar funcionalidades.

## Tareas

- [ ] Crear la solución `GestionTareas.sln` en la raíz del repositorio.
- [ ] Crear `GestionTareas.Web` como proyecto ASP.NET Core MVC.
- [ ] Crear `GestionTareas.Api` como proyecto ASP.NET Core Web API.
- [ ] Crear `GestionTareas.Application` como biblioteca de clases.
- [ ] Crear `GestionTareas.Domain` como biblioteca de clases.
- [ ] Crear `GestionTareas.Infrastructure` como biblioteca de clases.
- [ ] Crear `GestionTareas.Database` como SQL Server Database Project.
- [ ] Crear `GestionTareas.Tests` como proyecto de pruebas unitarias.
- [ ] Configurar los proyectos .NET con destino `net10.0`.
- [ ] Comprobar que `Nullable` e `ImplicitUsings` estén habilitados.
- [ ] Agregar todos los proyectos a la solución.
- [ ] Eliminar controladores, modelos, páginas y pruebas de ejemplo generados por las plantillas.
- [ ] Agregar la referencia de `Application` a `Domain`.
- [ ] Agregar las referencias de `Infrastructure` a `Application` y `Domain`.
- [ ] Agregar las referencias de `Api` a `Application`, `Infrastructure` y `Domain`.
- [ ] Agregar las referencias de `Tests` a `Api`, `Application` y `Domain`.
- [ ] Confirmar que `Web` no tenga referencias a otros proyectos de la solución.
- [ ] Confirmar que `Domain` y `Database` no tengan referencias a otros proyectos de la solución.
- [ ] Instalar `Microsoft.Data.SqlClient` en `Infrastructure`.
- [ ] Crear o actualizar `.gitignore` para .NET y Visual Studio.
- [ ] Restaurar los paquetes NuGet.
- [ ] Comprobar que el proyecto de pruebas pueda ejecutarse sin errores de configuración.
- [ ] Compilar la solución completa, incluido el proyecto de base de datos.
- [ ] Verificar que `bin/`, `obj/`, `.vs/` y archivos de usuario no aparezcan como cambios en Git.

## Notas

`Web` consumirá la API mediante HTTP y no debe referenciarla como proyecto.

`Api` referencia directamente a `Domain` porque sus mapeadores utilizan `Tarea` y `EstadoTarea`.

No se configurarán todavía cadenas de conexión, `HttpClient`, OpenAPI, serialización JSON, inyección de servicios ni manejo de errores. Esos elementos pertenecen a `TEC-003`.

No se deben agregar credenciales, cadenas de conexión reales ni archivos generados por el entorno.
