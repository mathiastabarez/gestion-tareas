## Notas

`TEC-003` depende únicamente de `TEC-001`; puede realizarse sin publicar la base de datos.

`AddApplication` y `AddInfrastructure` se crean como puntos de registro. Las implementaciones `TareaService` y `SqlTareaRepository` se agregarán durante `HU-001`.

El manejador global cubrirá inicialmente errores inesperados. El tratamiento de `TareaNoEncontradaException` se agregará cuando se implemente la consulta de tareas.

No se crearán controladores, DTOs, mapeadores, modelos ni consultas relacionados con tareas.

Los valores concretos de configuración y los pasos para iniciar ambos proyectos se documentarán en `TEC-004`.

api/program.cs:
AddControllers(): habilita los controladores de la API.
JsonStringEnumConverter: serializa los enums como "Pendiente" en lugar de 0.
AddProblemDetails(): configura el formato estándar para respuestas de error.
UseExceptionHandler(): captura globalmente las excepciones inesperadas y devuelve un error 500.
UseStatusCodePages(): genera ProblemDetails para respuestas vacías como un 404.
AddOpenApi() y MapOpenApi(): generan el documento OpenAPI solo en desarrollo.
UseHttpsRedirection(): redirige las solicitudes HTTP hacia HTTPS.
MapControllers(): publica las rutas definidas por los controladores.

web/program.cs:
AddControllersWithViews(): habilita MVC con controladores y vistas Razor.
AddHttpClient(...): registra IHttpClientFactory y un cliente para la API.
UseExceptionHandler("/Home/Error"): muestra la página de error fuera de desarrollo.
UseHsts() y UseHttpsRedirection(): aplican HTTPS.
UseStaticFiles(): permite servir CSS, JavaScript e imágenes desde wwwroot.
UseRouting() y MapControllerRoute(...): configuran el enrutamiento convencional.
