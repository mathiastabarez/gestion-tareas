# TEC-003 - Configurar la base de ejecución de la Web y la API

Estado: Pendiente

Fecha:

## Objetivo

Dejar `GestionTareas.Web` y `GestionTareas.Api` configurados para ejecutarse, recibir configuración y alojar funcionalidades posteriores, sin implementar todavía operaciones de tareas.

## Tareas

- [ ] Confirmar que `TEC-001` esté completada.
- [ ] Instalar los paquetes transversales necesarios:
  - `Microsoft.Extensions.DependencyInjection.Abstractions` en `Application`.
  - `Microsoft.Extensions.DependencyInjection.Abstractions` en `Infrastructure`.
  - `Microsoft.Extensions.Configuration.Abstractions` en `Infrastructure`.
  - Confirmar `Microsoft.AspNetCore.OpenApi` en `Api`.
- [ ] Crear `Application/DependencyInjection.cs` con el método `AddApplication`.
- [ ] Crear `Infrastructure/DependencyInjection.cs` con el método `AddInfrastructure`.
- [ ] Invocar `AddApplication` y `AddInfrastructure` desde `Api/Program.cs`.
- [ ] Configurar la API con:
  - Controladores.
  - Serialización de enums como texto.
  - Respuestas de error con `ProblemDetails`.
  - Un manejador global para errores inesperados.
  - OpenAPI habilitado en desarrollo.
  - Redirección HTTPS.
- [ ] Configurar la Web con:
  - MVC con controladores y vistas.
  - Archivos estáticos.
  - Enrutamiento convencional.
  - Redirección HTTPS.
  - Página de error fuera del entorno de desarrollo.
  - `IHttpClientFactory` para consumir la API.
- [ ] Crear una página inicial mínima con `HomeController` y `Views/Home/Index.cshtml` para comprobar el funcionamiento de MVC.
- [ ] Definir la clave `ConnectionStrings:GestionTareas` para la configuración de la API, sin guardar un valor real en el repositorio.
- [ ] Definir la clave `Api:BaseUrl` para la Web, sin guardar una dirección específica del equipo.
- [ ] Habilitar secretos de usuario en `Api` y `Web`, o utilizar variables de entorno para los valores locales.
- [ ] Confirmar que no sea necesario configurar CORS porque el navegador se comunicará con la Web y la Web llamará a la API.
- [ ] Restaurar los paquetes y compilar la solución sin errores.
- [ ] Ejecutar la API y comprobar que OpenAPI esté disponible en desarrollo.
- [ ] Ejecutar la Web y comprobar que la página inicial responda correctamente.
- [ ] Verificar que no se hayan agregado secretos, rutas locales ni valores específicos del equipo al repositorio.

## Notas

`TEC-003` depende únicamente de `TEC-001`; puede realizarse sin publicar la base de datos.

`AddApplication` y `AddInfrastructure` se crean como puntos de registro. Las implementaciones `TareaService` y `SqlTareaRepository` se agregarán durante `HU-001`.

El manejador global cubrirá inicialmente errores inesperados. El tratamiento de `TareaNoEncontradaException` se agregará cuando se implemente la consulta de tareas.

No se crearán controladores, DTOs, mapeadores, modelos ni consultas relacionados con tareas.

Los valores concretos de configuración y los pasos para iniciar ambos proyectos se documentarán en `TEC-004`.
