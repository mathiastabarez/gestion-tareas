# TEC-002 - Crear y publicar el esquema inicial de la base de datos

Estado: Completada

Fecha: 05/10/2026

## Objetivo

Definir el esquema inicial de la base `GestionTareas` en el SQL Server Database Project y comprobar que pueda compilarse y publicarse correctamente.

## Tareas

- [x] Confirmar que `TEC-001` esté completada.
- [x] Configurar `GestionTareas.Database` con plataforma de destino SQL Server 2019.
- [x] Crear el archivo `dbo/Tables/Tareas.sql`.
- [x] Confirmar que `Tareas.sql` esté incluido en el `.sqlproj` con acción de compilación `Build`.
- [x] Definir la tabla `dbo.Tareas` con la siguiente estructura:
  - `Id`: `int`, clave primaria e identidad con nombre `PK_Tareas`.
  - `Titulo`: `nvarchar(150)` obligatorio.
  - `Descripcion`: `nvarchar(1000)` opcional.
  - `Estado`: `nvarchar(20)` obligatorio.
  - `FechaCreacion`: `datetime2` obligatorio.
  - `FechaVencimiento`: `date` opcional.
  - Restricción `CK_Tareas_Estado` para permitir únicamente `Pendiente`, `EnCurso` y `Completada`.
- [x] Comprobar que el proyecto SQL compile sin errores.
- [x] Confirmar que la compilación genere un archivo `.dacpac`.
- [x] Publicar el esquema en una base de desarrollo llamada `GestionTareas`.
- [x] Verificar que la tabla, la clave primaria, la identidad y la restricción de estado hayan sido creadas.
- [x] Publicar nuevamente y comprobar que no se generen cambios inesperados.
- [x] Insertar una tarea válida para comprobar el esquema.
- [x] Comprobar que SQL Server rechace un estado no permitido.
- [x] Eliminar los datos utilizados para la comprobación.
- [x] Verificar que no se hayan agregado credenciales ni datos específicos del equipo al repositorio.

## Notas

El proyecto SQL define el esquema; no contiene consultas utilizadas por la aplicación.

La plataforma de destino establece SQL Server 2019 como compatibilidad mínima y no identifica una instancia concreta.

No se agregarán datos iniciales, procedimientos almacenados, vistas ni índices adicionales en esta tarea.

La API se conectará a la base en tareas posteriores mediante `Microsoft.Data.SqlClient`.

Los valores concretos y pasos para publicar la base se documentarán posteriormente en la guía de ejecución.

## Resultado

Se creo base de datos funcional.
