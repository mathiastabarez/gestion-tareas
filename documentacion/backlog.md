# BACKLOG - GESTIÓN DE TAREAS

## Regla de uso

- Las historias de usuario se documentan en `requisitos/`.
- Las tareas técnicas se documentan en `tareas/`.
- El orden dentro de cada sección indica la prioridad de implementación.
- Al cambiar el estado de un elemento, debe moverse a la sección correspondiente.
- Una historia se considera completada cuando funciona desde la Web hasta SQL Server y sus pruebas unitarias están aprobadas.
- Una tarea técnica se considera completada cuando su resultado fue comprobado.
